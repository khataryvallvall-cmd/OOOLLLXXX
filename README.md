# تجهيز التطبيق للنشر على GitHub Pages

## الملفات
- `index.html` — التطبيق نفسه (بعد إضافة القفل وسلوك التطبيق الأصلي)
- `manifest.json` — ملف تعريف PWA (اسم التطبيق، الألوان، الأيقونات)
- `service-worker.js` — يجعل التطبيق يفتح فورًا وبدون شريط المتصفح بعد إضافته للشاشة الرئيسية

## خطوات النشر
1. أنشئ مستودع (repository) جديد على GitHub، مثلاً باسم `video-cards-app`.
2. ارفع الملفات الثلاثة (`index.html`, `manifest.json`, `service-worker.js`) في **جذر** المستودع مباشرة (وليس داخل مجلد فرعي).
3. أضف أيقونة تطبيقك بصيغة PNG بحجمين:
   - `icon-192.png` (192×192 بكسل)
   - `icon-512.png` (512×512 بكسل)
   وارفعهما أيضًا في جذر المستودع بنفس هذين الاسمين تمامًا (يمكنك تصغير/تكبير نفس الأيقونة لديك للحصول على المقاسين).
4. من إعدادات المستودع: `Settings → Pages` اختر `Branch: main` و`Folder: / (root)` ثم احفظ.
5. بعد دقيقة أو دقيقتين سيظهر رابط الموقع، مثل:
   `https://username.github.io/video-cards-app/`
6. افتح الرابط من متصفح الجوال (Chrome على أندرويد)، ثم من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية" / Add to Home screen**. سيظهر التطبيق بأيقونتك، وعند فتحه سيعمل بملء الشاشة بدون أي شريط متصفح — تمامًا كتطبيق أندرويد عادي.

## ملاحظات مهمة
- **كلمة المرور** تُحفظ داخل جهاز المستخدم فقط (لا تُرسل لأي خادم)، وتُخزَّن بصيغة مُجزّأة (hash) وليست نصًا واضحًا، وتظل محفوظة بين مرات فتح التطبيق طالما لم يمسح المستخدم بيانات المتصفح.
- زر القفل 🔒 أعلى يسار الشاشة يتيح للمستخدم قفل التطبيق يدويًا في أي وقت.
- إذا نسي المستخدم كلمة المرور: زر "نسيت كلمة المرور؟ إعادة الضبط" يمسحها ليُنشئ واحدة جديدة (هذا لا يمسح باقي بيانات التطبيق).
- روابط الفيديو في المتغير `VIDEO_LINKS_RAW` تبقى كما كانت — لم تُغيَّر آلية إضافة الروابط.
- تجربة إخفاء التحديد/النسخ لن تظهر بشكل كامل داخل معاينة الأدوات هنا، لكنها تعمل بشكل صحيح على GitHub Pages وعند تشغيله كتطبيق مضاف للشاشة الرئيسية.
